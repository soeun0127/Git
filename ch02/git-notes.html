SMALL STEPS, BIG PROGRESS

코드를 기록하고,
함께 성장하기.

좋은 개발 습관은 작은 기록에서 시작됩니다. 오늘의 변경 사항을 정리하고, Git으로 작업의 흐름을 관리해 보세요.

명령어 살펴보기 ↗ 
# 변경 사항 확인
$ git status

# 커밋할 파일 선택
$ git add index.html

# 작업 기록 남기기
$ git commit -m "Add page"

# 원격 저장소에 업로드
$ git push origin main
✓ progress saved

Git workflow

변경 사항이 기록되는 기본 흐름

⌘

01. Working Directory

프로젝트 파일을 직접 만들고 수정하는 공간입니다. 변경 사항은 아직 커밋되지 않았습니다.

git diff
＋

02. Staging Area

다음 커밋에 포함할 변경 사항을 골라 임시로 올려두는 공간입니다.

git add .
↗

03. Repository

스테이징한 변경 사항을 커밋으로 기록하고, 필요하면 원격 저장소에 공유합니다.

git commit · git push
